# Unrefereed candidate, version 1.0.1

Written analytic classification for homogeneous open nearest-neighbour chains with a normalised rank-one local projector and a forbidden vector having exactly two equal nonzero Schmidt probabilities. No additional boundary penalties. Every ambient finite dimension d >= 2; every length N >= 2.

The candidate classifies gapped versus gapless interactions in that class. It does not classify arbitrary unequal Schmidt probabilities, general rank-two projectors, periodic chains, or infinite-volume GNS gaps. Complementary results retain their narrower scope.

Finite exact/numerical replay is producer-side corroboration, not a formal proof of the universal theorem. Supplied referee checks provide implementation diversity; unaffiliated authorship has not been authenticated. External specialist review, independent reproduction, priority and impact remain unestablished.
